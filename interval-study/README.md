# Interval Study source

This directory contains the source for the self-contained static player at
[`docs/interval-study/`](../docs/interval-study/). It simulates the coupled
sound and interval circuits in the browser; the bundled piano recordings only
render the sampled outcomes.

Run `npm install` followed by `npm run build` from this directory to rebuild
the static page. The build writes only to `../docs/interval-study/`.

The included Salamander Grand Piano recordings by Alexander Holm are licensed
CC BY 3.0; the full attribution is bundled with the player.
